# 🧮 React Calculator (Built with Vite)

This is a fully functional calculator built using **React** and **Vite**. It performs all the essential arithmetic operations and replicates the functionality of a standard handheld calculator — with the exception of the **ESC key**.

## 🚀 Features

- Basic arithmetic operations: addition, subtraction, multiplication, division
- Clear (`C`) and multilevel calculation functionality
- Handles decimals and parentheses
- User-friendly interface with responsive design
- Keyboard and button input support (except `ESC` key)
- Built with modern tools: **React + Vite**

## 🛠️ Tech Stack

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [JavaScript (ES6+)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
- [HTML5](https://developer.mozilla.org/en-US/docs/Web/Guide/HTML/HTML5)
- [CSS3](https://developer.mozilla.org/en-US/docs/Web/CSS)
